The caves play the song in this folder, named:

    cave_wave.ogg   (best)   or   cave_wave.mp3   or   cave_wave.wav

If more than one exists, .ogg wins, then .mp3, then .wav.
The song repeats for as long as you are in the caves.
Godot cannot read .m4a / .aac, so convert those to .ogg or .mp3 first.
Open the project in the Godot editor once so it imports new files.
